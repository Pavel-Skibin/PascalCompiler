# Язык Pascal

В проекте реализовано подмножество Pascal, достаточное для демонстрации компилятора и двух backend-вариантов исполнения.

## Поддерживаемые типы

1. `integer`
2. `char`
3. `boolean`
4. `string`
5. `double`
6. одномерные массивы

## Поддерживаемые операции

1. Арифметика: `+`, `-`, `*`, `/`, `div`, `mod`
2. Сравнения: `=`, `<>`, `>`, `<`, `>=`, `<=`
3. Логика: `not`, `and`, `or`

## Управляющие конструкции

1. `if then else`
2. `while do`
3. `repeat until`
4. `for to/downto do`
5. `break`
6. `continue`

## Подпрограммы

1. Процедуры.
2. Функции.
3. Вложенные подпрограммы.
4. Передача параметров по значению.
5. Рекурсия.

## Ввод и вывод

1. `Write`
2. `WriteLn`
3. `Read`
4. `ReadLn`

## Системные функции

1. `Inc`
2. `Dec`
3. `Abs`

## Ограничения

1. Нет передачи по ссылке.
2. Поддерживается не весь Pascal, а только реализованное подмножество.
3. Простая VM сейчас покрывает только базовые вычисления и управление потоком.
