# Оптимизации

В проекте реализованы примитивные оптимизации на уровне AST.

## Что делает AstOptimizer

1. Вычисляет константные выражения заранее.
2. Упрощает ветвления, если условие известно на этапе компиляции.
3. Убирает заведомо недостижимые конструкции.
4. Нормализует отдельные узлы дерева перед исполнением.

## Что не делает

1. Не выполняет глобальный анализ потока данных.
2. Не строит SSA.
3. Не делает агрессивную машинно-ориентированную оптимизацию.

## Зачем это нужно

1. Сокращает объем вычислений на этапе исполнения.
2. Упрощает дерево.
3. Демонстрирует этап компилятора между семантикой и исполнением.
